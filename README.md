# artix-installer
My Artix Installer for NVME, configure host usn and passwd by urself

default host is=nyxartix

it using hyprland as wm
and using ufw as firewall
cups for print services
avahi for scanning service
ext-4 for nvme partition
grub as bootloader
sddm as display manager
iwd as it's internet backend
